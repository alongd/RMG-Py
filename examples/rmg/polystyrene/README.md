# Polystyrene method-of-moments example

This example runs the method-of-moments polymer reactor on the public polymer
branches of RMG-Py and RMG-database.

## Setup

Check out the RMG-Py `polymer-mom` branch and the RMG-database `polymer` branch.
The database revision used for this example is `cd86d4e1c`. Build RMG-Py (the
repository's normal `make` or `python setup.py build_ext --inplace` procedure)
and use the resulting checkout on `PYTHONPATH`.

Point RMG at the database with an `rmgrc` file. For example, in the directory
from which the run is launched:

```text
database.directory : /absolute/path/to/RMG-database/input
```

The `rmgrc` file is read by RMG's configuration system; no database files need
to be copied into or modified in RMG-Py.

## Run

From this directory, with the RMG-Py checkout on `PYTHONPATH`, run:

```bash
python ../../../rmg.py input.py
```

The input creates a polystyrene polymer pool, an inert nitrogen/argon gas
environment, and a hybrid polymer reactor at 1000 K and 1 bar. The output
directory contains the generated core and edge mechanisms, chemistry and
thermodynamic files, solver profiles, and the HTML model summary. The model
includes the polymer moments and any light products generated by the selected
chemistry, including styrene when it is produced.
